## Store assets

All present. Regenerate with `make-graphics.ps1` and `capture.ps1` after any UI change.

| Asset | Spec | Status |
|-------|------|--------|
| App icon | 512×512 PNG, no alpha | ✅ `icon-512.png` |
| Feature graphic | 1024×500 PNG/JPG, no alpha | ✅ `feature-graphic.png` |
| Phone screenshots | 2–8 | ✅ `ph-01-search.png`, `ph-02-settings.png` (1080×2340) |
| 7-inch tablet | up to 8 | ✅ `t7-01-search.png`, `t7-02-settings.png` (1200×1920) |
| 10-inch tablet | up to 8 | ✅ `t10-01-search.png`, `t10-02-settings.png` (1600×2560) |

Both graphics are generated by [`make-graphics.ps1`](make-graphics.ps1) and saved as opaque
24-bit RGB, because Play rejects an alpha channel on these two. The icon is drawn from the
same path data as `res/drawable/ic_logo.xml`, so the store icon and the launcher icon are
identical rather than merely similar.

Screenshots are captured in demo mode so no real contact is ever published. All six are
produced by [`capture.ps1`](capture.ps1), which installs the APK, launches demo mode, types
343 and grabs both screens — reading key positions from the live view hierarchy so the same
script works at every resolution:

```powershell
.\capture.ps1 -Serial emulator-5556 -Prefix t7
```

The tablet shots come from AVDs created for the purpose:

| AVD | Device definition | Resolution | Density |
|-----|-------------------|-----------|---------|
| `T9_Phone`    | pixel_7               | 1080×2340 | 440 |
| `T9_Tablet7`  | 7in WSVGA (Tablet)    | 1200×1920 | 240 |
| `T9_Tablet10` | 10.1in WXGA (Tablet)  | 1600×2560 | 320 |

## Data safety form

- **Personal info → Contacts**: collected? **No.** The app reads contacts on-device to
  build its index; nothing is transmitted or stored off-device. Declare "no data
  collected or shared".
- **Permissions**: `READ_CONTACTS`, `CALL_PHONE`. Neither is in Google's restricted
  permission set (that covers SMS and Call Log), so no declaration form is required.
- **Privacy policy URL**: required because the app accesses contacts. Served from `/docs`
  in this repository via GitHub Pages —
  https://wirtheim.github.io/t9-still-alive-dialer/privacy.html
